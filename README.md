# Ad Compliance Check（发布前合规检查）

写中文文案时，把广告法风险表达当场标出来：极限词、功效与安全保证、收益承诺、缺出处的权威背书。每一处都写明原因、法律依据和改法。

纯本地运行，不联网，不调用 AI，不上传任何笔记内容。

> An Obsidian plugin that flags risky claims in Chinese advertising copy as you write — superlatives, health and income promises, unsupported endorsements — with the legal basis and a safer wording for each. Fully offline. The word lists target the Advertising Law of the People's Republic of China, so the interface is in Chinese.

## 能做什么

- **编辑器实时标注**：风险表达下方画波浪线，红色为禁用、橙色为慎用、蓝色为需依据。鼠标停留显示原因、依据和建议。
- **检查面板**：侧边栏列出当前笔记的全部风险表达，点击跳到原文，可一键加入白名单。
- **检查报告**：把结果复制成 Markdown 表格，发给客户或同事。
- **按客户加严**：给某个文件夹追加行业词库和专用禁用词，只对该文件夹生效。
- **单篇设置**：在笔记属性里为这一篇追加词库，或关闭检查。
- **自定义词库与白名单**：加入自己行业、平台或客户要求的词。

## 内置词库

| 词库 | 默认 | 内容 | 主要依据 |
| --- | --- | --- | --- |
| 绝对化用语 | 开 | 最佳、顶级、第一、唯一、首选等 | 广告法第九条第（三）项 |
| 效果与安全保证 | 开 | 根治、100%有效、无副作用、立竿见影等 | 广告法第十六、十七、十八、二十八条 |
| 招商加盟与收益承诺 | 开 | 稳赚不赔、零风险、几个月回本、月入几万等 | 广告法第二十五条 |
| 权威背书与荣誉 | 开 | 驰名商标、特供、专家推荐、数据显示、专利等 | 广告法第九、十一、十二条；商标法第十四条 |
| 疾病与医疗用语 | 关 | 治疗、消炎、降血糖及疾病名称等 | 广告法第十七条 |
| 食品与保健食品 | 关 | 增强免疫力、减肥、零添加、纯天然等 | 食品安全法第七十三条；广告法第十八条 |
| 化妆品 | 关 | 药妆、祛疤、生发、零刺激等 | 化妆品监督管理条例第四十三条 |
| 教育培训 | 关 | 包过、保证提分、命题人、通过率等 | 广告法第二十四条 |
| 房地产 | 关 | 升值、投资回报、几分钟直达、学区房等 | 广告法第二十六条 |
| 迷信内容 | 关 | 招财、转运、开光等 | 广告法第九条第（八）项 |

行业词库默认关闭，建议按文件夹或单篇笔记开启，避免在无关笔记里产生干扰。

## 怎么用

1. 安装并启用后，直接写作，风险表达会被标出。
2. 点击左侧盾牌图标，或运行命令“打开检查面板”，查看整篇结果。
3. 在 **设置 → Ad Compliance Check** 里开关词库、填写自定义词库和白名单。

### 自定义词库格式

每行一条，只有词语必填：

```
词语 | 级别 | 替换词 | 说明
门店第一 | 禁用 | 本地开业较早 | 无排名依据
/保\d+年/ | 需依据
```

级别写 `禁用`、`慎用` 或 `需依据`，不写按慎用处理。填了替换词，面板和悬停提示里会出现“换成…”按钮，多个替换词用顿号隔开。自定义词与内置词重合时，以自定义为准。写成 `/…/` 的词语按正则表达式匹配。`#` 开头的行是注释。

### 单篇笔记设置

```yaml
---
合规词库: [疾病与医疗用语, 食品与保健食品]
合规检查: false
---
```

`合规词库` 为这一篇追加词库；`合规检查: false` 关闭这一篇的检查。两个属性名可在设置里修改。

### 不检查的内容

笔记属性、代码块、行内代码、链接地址、双链和注释不参与检查。

## 局限

- 本插件按词库匹配，不理解语境。命中是提醒你回看这一句，不等于违法；没有命中也不等于合规。
- 同一个词在不同语境下性质不同。常见的非广告用法（如“最好先做调研”“第一步”）已排除，仍遇到误报可加入白名单。
- 不构成法律意见。涉及医疗、保健食品、招商加盟等高风险内容，请以监管规定和专业意见为准。

## 安装

在 Obsidian 的 **设置 → 第三方插件 → 浏览** 中搜索 “Ad Compliance Check”。

手动安装：从 Releases 下载 `main.js`、`manifest.json`、`styles.css`，放入 `<库>/.obsidian/plugins/ad-compliance-check/`，重启 Obsidian 后启用。
